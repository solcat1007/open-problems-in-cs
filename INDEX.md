## 维护提示

新增或更新档案后，请同步检查本页：字段变化（状态、门槛、标题）会导致索引与档案不一致。
可用以下命令重新生成本页的「按状态 / 按门槛」段落：

```bash
python - <<'PY'
import re, glob, collections
rows=[]
for f in glob.glob('volumes/*/problems/*.md'):
    s=open(f,encoding='utf-8').read()
    i=re.search(r'# #(\d+)',s); st=re.search(r'\*\*状态\*\*：`([^`]+)`',s)
    th=re.search(r'\*\*参与门槛\*\*：([^\n]+)',s)
    rows.append((int(i.group(1)),st.group(1),th.group(1).strip()))
for key,idx in [('状态',1),('门槛',2)]:
    d=collections.defaultdict(list)
    for r in rows: d[r[idx]].append(r[0])
    print('==',key,'==')
    for k,v in sorted(d.items()): print(k,':',','.join(map(str,v)))
PY
```
