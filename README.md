# Open Problems in Computer Science

> 一份关于计算机科学 **100 个开放问题** 的结构化研究档案库。
> 每个问题一份档案：**形式化陈述 · 已知障碍 · 当前最好结果 · 研究路线图 · 可核查文献 · 可运行实验**。

---

## 这个仓库是什么

计算机科学有一批问题，被反复提及、被写进教材、被拿来做播客素材，但**始终没有答案**。它们散落在论文的 "Open Problems" 小节、会议的 problem session、以及各种非正式的难题清单里，缺少一个统一的、结构化的、**诚实标注状态**的整理。

这个仓库做这件事：为 100 个这样的问题各建一份**档案（dossier）**。

每份档案回答七个问题：

| 栏目 | 回答什么 |
|---|---|
| 形式化陈述 | 这个问题在数学上到底在问什么？能否写成一个可判定真假的命题？ |
| 为什么困难 | 难在哪一层？是技术障碍还是**原理性障碍**？ |
| 当前最好结果 | 已知的最强上界、最弱下界、条件性结果分别是什么？ |
| 研究路线图 | 学界在试哪些路线？每条路线卡在什么地方？ |
| 关键文献 | 可核查的原始论文与综述，标注出处与年份 |
| 常见误区 | 外行最容易搞错的地方是什么？哪些"证明"必然有错？ |
| 可运行实验 | 能不能写代码亲手验证某个已知的部分结果？ |

---

## 这个仓库不是什么

这一条必须写在最前面，因为它决定了整个仓库的可信度。

**本仓库不声称解决任何问题。**

所收录的 100 个问题中，**58 个是纯理论开放问题**——需要在数学上证明或否证一个命题。它们至今**没有任何人有答案**。其中若干是克莱数学研究所的千禧年大奖问题，悬赏 100 万美元。

因此：

- 档案中的"研究路线图"是**对学界现状的整理**，不是解题方案。
- 档案中的"可运行实验"复现的是**已知的部分结果**（例如某个下界的构造性验证），不是新结果。
- 任何声称在这些档案中找到"P vs NP 的证明"的读者，请直接查阅 [METHODOLOGY.md](METHODOLOGY.md) 中关于**原理性障碍**的章节——那里会说明为什么绝大多数此类"证明"在提出后几分钟内就能被排除。

**如果你在 GitHub 上看到某个仓库宣称解决了 P vs NP、黎曼猜想或 NP vs Co-NP，它几乎必然是错的。** 本仓库的目标恰恰相反：把"为什么这么难"讲清楚。

## 状态分级

每个问题都标注一个状态等级。分级标准见 [METHODOLOGY.md](METHODOLOGY.md)：

| 标记 | 含义 |
|---|---|
| `OPEN` | 完全开放，无任何方向的确定性结论 |
| `OPEN-BARRIER` | 开放，且已知存在**原理性障碍**——某些证明路线在原理上不可能成功 |
| `CONDITIONAL` | 在特定未证明假设下已有确定结论（如"若 ETH 成立则……"） |
| `PARTIAL` | 已有重要的部分结果，但核心问题未解 |
| `SETTLED-RECENT` | 近年内已被解决（档案保留，用于记录方法与历史） |

`OPEN-BARRIER` 是本仓库着重要标注的一类。它比单纯说"未解决"信息量大得多：它告诉你**不要往哪个方向走**。

## 按难度与门槛索引

不同问题的"参与门槛"差得极远，这一点通常没人说清楚：

| 门槛 | 意味着什么 | 例子 |
|---|---|---|
| 需要新的数学工具 | 现有工具已被证明不够用，可能要先发展新理论 | #1 P vs NP、#18 电路下界 |
| 需要长期工程积累 | 方向明确，但需要大规模实验与器件进步 | #59 量子纠错规模化、#61 量子比特错误率 |
| 可以立刻上手做实验 | 有明确的基准、数据、可复现的方法 | #45 LLM 幻觉检测、#48 深度伪造检测 |
| 主要缺的是方法论 | 不是难在技术，而是难在研究范式的确立 | #90 软件工程研究的规模化 |

如果你是想**实际动手**的读者，直接从第四类开始。这类问题在 [`volumes/04`](volumes/04-ai-machine-learning/)、[`volumes/09`](volumes/09-software-engineering/)、[`volumes/10`](volumes/10-computational-biology/)、[`volumes/11`](volumes/11-human-computer-interaction/) 里最密集。

## 怎么用这个仓库

**想快速了解某个问题**：查 [PROBLEMS.md](PROBLEMS.md) 找到编号，打开对应档案的"形式化陈述"和"当前最好结果"两节，五分钟够用。

**想判断一个"证明"是否可信**：看该问题的"常见误区"节。绝大多数错误证明都踩在其中某一条上。

**想动手做研究**：看"研究路线图"节，挑一条你所在方向能贡献的路线；再看"可运行实验"，先把已知的部分结果亲手复现一遍——这是判断自己是否真的理解了问题的最快方式。

**想给孩子/学生讲清楚某个问题**：档案的"形式化陈述"和"常见误区"两节可以直接用作讲解稿，比大多数科普材料准确。

## 引用与致谢

本仓库的内容是对**已公开发表的学术工作**的整理与转述。每份档案的"关键文献"节给出原始出处。若发现引用有误、结论过时或表述不准确，欢迎提交 Issue——**准确性是这个仓库唯一的卖点**。

对于清单中少数涉及近年工作的条目，档案中会显式标注"待核实"（`[待核实]`），表示该结论来自二手来源、尚未核对原始论文。请不要把带此标记的内容当作确定结论引用。
