## 一、本册与第一卷的区别

第一卷（计算复杂性理论）问的是**类与类之间的关系**：P 是否等于 NP、NC 是否等于 P、电路能否有强下界。这些问题在结构上离具体算法很远，且几乎全部被**相对化 / 自然化 / 代数化**三重障碍夹住。

本册问的是**具体算法结构**的性质：

- 一个已知的算法（Held–Karp 的动态规划、splay 树的伸展、Dinic 的分层图）**是否已经最优**？
- 在**限制输入结构**（平面图、排列图、直线站点）之后，问题的复杂度落在哪一侧？
- 当结论只能是条件性的时候，**依赖的假设是什么**，以及这一点如何改变结论的强度？

三个后果值得提前说明：

**第一，本册的问题大多"看起来可达"。** 第一卷的很多问题不知道从哪下手；本册的许多问题有明确的技术抓手——一个具体的算法、一个具体的图类、一个具体的下界函数。这不意味着它们更容易，而意味着**失败的路线更容易被定位**（例如 splay 树的 interleave 界已被证明不可能证明动态最优性，这是一条已知的死路）。

**第二，本册大量结论是"上界 + 上界"，下界稀少。** 这是全清单中最容易出错的地方。看到"某算法是 $O(2^n n^2)$"要立刻意识到这是**上界**；看到"某问题是 NP 完全的"要意识到这是**相对难度**而非**下界**。本册的十份档案中都单列了"读表要点"，专门防止这类混淆。

**第三，本册的"开放"有多种形态。** 有的是"某具体命题未被判定"（#23 中 $\Delta=6$ 的平面图）；有的是"指数未知、下界空白"（#28 最大流）；有的是"猜想依赖全称量词，无法单点攻击"（#26 splay 树）；还有的是"分类表没填满，且不知道填表该用什么规则"（#27）。把"开放"当成同一种东西，会严重误判研究难度。

## 三、为什么"细粒度复杂性"成为主流范式

过去二十年，本册这一领域最显著的变化，是研究重心从"多项式 vs 指数"转向"**指数/多项式的具体指数是多少**"。

原因有三层。

**其一，P vs NP 型的问题长期无进展，而"精确指数"这一层是可攻的。** 既然无法证明 3-SAT 需要指数时间，那就退一步问：它需要 $1.3^n$ 还是 $1.5^n$？这类问题对上界一侧通常是**可达的工程**——改进分支策略、改进测量工具、改进代数工具，都能带来可发表的进展。于是形成了一个**有稳定产出**的研究节奏。

**其二，细粒度视角把大量原本孤立的结果串成了网络。** 一旦确立"$k$-SAT 的指数不可能改善"这一枢纽，就可以通过保参数的归约把结论迁移到别处：正交向量、$k$-SUM、APSP、命中集、直到 TSP。这形成了一个**统一的假设—归约—结论**体系，比零散的问题特化归约有效得多。本册 #21 与 #30 正是这一体系的代表。

**其三，细粒度复杂性给出了"条件性下界"这一可操作的中间形态。** 它明确承认自己带前提，从而绕开了"无条件证明做不到"的死结。这是它方法论上最诚实、也最实用的一点——**只要你把前提写出来**。

代价同样明确：**全部结论的可信度与假设绑定**。一个细粒度下界被引用一百次，不会让它变得更可信；它只会让假设被更多人默认接受。

## 四、SETH 作为假设基础的支配地位

本册（以及第一卷的 #11、#12）中，绝大多数条件性下界最终都归到 **SETH** 或它的弱化版本 **ETH** 上。这种"支配地位"有好处也有风险。

**好处**：SETH 是一个**单一、陈述简短、无需额外结构**的假设。相对于唯一游戏猜想（UGC）那种需要概率/傅里叶分析背景的假设，SETH 的门槛低得多：它只说"$k$-SAT 不能做到 $2^{(1-\varepsilon)n}$，对足够大的 $k$"。因此它可以被大量工作直接使用。

**风险一：假设的强度不透明。** SETH 蕴含 ETH，但它的**真正强度**（它是否等价于某个更熟悉的命题）并不清楚。把一个建立在 SETH 上的结论说成"证明了 X 不可能"是最常见的过度引用。

**风险二：它是单向街。** 我们既无法证明也无法否证 SETH；而**否证**它（即给出更快的 SAT 算法）会立即导出电路下界——这是本册 #30 讨论的核心张力。也就是说，使用 SETH 的社区，实际上是在一个"推翻它反而更有价值"的假设上工作。

**风险三：不是所有问题都适合挂在 SETH 上。** 本册 #28 最大流就是反例：它是一个多项式问题，约束结构（守恒 + 容量）难以承载 SAT 式编码，因此 SETH 路线给不出下界，而下界栏至今空白。**"有下界"与"没有下界"在本册中并存，这个对比本身比任何单条下界更有教学价值。**

**引用规范（本册强制）**：任何条件性结论必须写成"**若 SETH 成立，则 …**"。省掉前提即视为错误陈述。

## 五、哪些问题最适合动手实验

十题中有七题的门槛标为"可以立刻上手做实验"。它们按可做性排序如下。

**最适合入门（无需任何外部依赖，纯标准库即可）**：

- **#21 TSP 的细粒度下界** —— 位掩码 DP 的指数曲线、1-tree 下界与最优解的 gap。这是理解"上界与下界是两种东西"的最佳入口。
- **#26 Splay 树的动态最优性** —— 实现 splay、平衡树、静态最优树，在顺序/工作集/两端交替序列上对比；再实现 Wilber 的 interleave 下界，亲眼看到它与最优树的缝隙。
- **#30 精确算法的指数时间下界** —— DPLL 在随机 3-SAT 与鸽巢实例上的指数曲线，并切换分支启发式观察曲线如何变化。**这个实验最重要的收获是反面的：它揭示了为什么实测永远不能给出下界。**

**需要一点数据结构与建模工具**：

- **#22 最大割的参数化复杂性** —— Edwards–Erdős 界的超出量与搜索树规模的关系。
- **#28 最大流问题的细粒度复杂性** —— 对比 Edmonds–Karp 与 Dinic 在对抗实例上的差距；并做一次"$k=2$ 多项式 / $k=3$ NP 难"的对照。
- **#27 图类上的 NP 完全问题分类** —— 在不同图类实例上对比回溯与 ILP 的经验增长率。
- **#29 排列图上的哈密顿回路** —— 由置换构造排列图，交叉验证暴力与 ILP 求解器。

**需要几何库**：

- **#24 Voronoi 图 d 维组合复杂性下界** —— 用 `scipy.spatial` / Qhull 计算 $d = 2,3,4$ 的 Delaunay 规模并拟合指数；另外亲手构造一个高复杂度构型，体会"下界是构造出来的，不是跑出来的"。

**统一警告**：本册所有实验的共同结论都是同一条——**有限规模的实测无法推出渐近结论**。上界可以通过实现来体会，下界只能通过证明。如果某个实验让你觉得"好像证明了下界"，那一定是实验设计出了问题。

**不适合实验的两题**：

- **#23 平面图的边着色问题** —— 可以做边着色算法与第二类构造的验证，但 $\Delta = 6$ 的判定在原理上不可暴力搜索（判定问题本身对 $\Delta=3$ 就 NP 完全）。
- **#25 串行任务的高效并行化** —— 可以测加速比与关键路径，但实测主要反映工程因素（语言、GIL、内存带宽），理论层要面对的是电路下界。

## 六、建议阅读顺序

**若你想先建立方法论**：先读 [#30 精确算法的指数时间下界](problems/30-exponential-time-lower-bounds.md)，理解"上界 / 下界 / 条件性 / 障碍"四种陈述的区别；再读 [#21](problems/21-tsp-fine-grained.md) 与 [#28](problems/28-max-flow-fine-grained.md) 这一对有下界 / 无下界的对照。**读了这三份，本册其余档案的表格就不会再被误读。**

**若你想动手**：直接跳到"五、哪些问题最适合动手实验"中列出的脚本。每个档案的"可运行实验"一节都写明了**该实验不能说明什么**——先读这一条，再动手。

**若你关心图与组合结构**：[#23](problems/23-planar-edge-coloring.md) → [#27](problems/27-np-complete-classification.md) → [#29](problems/29-hamiltonian-permutation-graphs.md) 构成一条线，从"单一猜想的最后一格"到"整张分类表"再到"一个被误标为开放的条目"。

**若你关心"某算法是否已最优"**：[#26](problems/26-splay-dynamic-optimality.md) 与 [#21](problems/21-tsp-fine-grained.md) 是同一母题的两个极端——前者连常数竞争比都未达到，后者已有紧到 $(2-\varepsilon)^n$ 的条件性边界。
