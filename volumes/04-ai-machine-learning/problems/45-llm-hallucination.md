# #45 大语言模型的幻觉问题

**状态**：`OPEN`
**领域**：AI 与机器学习
**首次提出**：随大语言模型规模化应用而浮现，约 2020 年起的系统性研究课题
**参与门槛**：可以立刻上手做实验

---

## 一句话概述

大语言模型会以**完全自信的语气**输出错误内容，而我们既无法可靠地检测它，也无法从原理上解释它为什么必然发生。

## 形式化陈述

**这个问题无法被形式化为一个可判定真假的命题。** 这一点的说明本身比强行形式化更有价值。

原因有三：

**其一，"幻觉"没有公认定义。** 目前被广泛引用的是三分法：*input-conflicting*（与输入矛盾）、*context-conflicting*（与上下文矛盾）、*fact-conflicting*（与事实矛盾）。但"与事实矛盾"需要一个事实真值源，而这个源本身可能是错的、过时的、或有争议的。对于"2025 年某公司的营收是多少"这类问题，"事实"本身就在动态变化。

**其二，开放生成没有标准答案。** 判定"这段话是否包含幻觉"需要判定它是否包含至少一个假陈述。而自然语言文本的真值判定通常需要世界知识 + 推理，这本身是个未解问题。

**其三，评测本身受污染。** 公开基准的测试集可能出现在训练数据中，导致报告的分数无法反映真实的泛化能力。这是一个**方法论**层面的污染，而非技术层面的。

可以形式化的**子问题**是：

> 给定模型对同一问题的 $N$ 次采样输出，能否构造一个统计量 $S$，使其与"该次输出是否包含事实错误"具有高相关？

这个子问题是有意义的，也是当前最活跃的研究方向（见下节"语义熵"）。但它**不等价于**原问题——它衡量的是"内部一致性"，而模型可以**一致地错**。

## 为什么困难

**（一）生成与验证的不对称性**

在**受限**设定下（如多项选择、有明确答案的问答），幻觉检测是可以形式化的。但一旦进入开放生成，验证一个陈述需要的能力往往**不弱于**生成它。这与 [#1 P vs NP](01-p-vs-np.md) 中的验证/求解不对称性在**结构上**有相似之处——但请注意，这只是一个类比，二者没有归约关系，不应把复杂度理论结论直接搬到 NLP 上。

**（二）模型无法可靠地知道"自己不知道"**

一个理想的系统应当能区分三类情况：确实知道、不知道且能承认、不知道但错误地回答。第三类就是幻觉。

Kadavath 等人 2022 年的工作表明，模型对自己答案正确性的**内部评估**能力显著高于随机猜测——但**远不到可靠**。这种能力称为"校准"（calibration），而 RLHF 训练通常**损害**校准：为了讨好人类评分者，模型倾向于给出自信的回答，而非承认不确定。

**（三）表示与事实性的解耦**

模型参数中存储的是**统计共现模式**，而非结构化的事实库。"北京是中国首都"与"北京有 2100 万人口"在参数中的存储形式没有本质区别。模型没有内在机制去区分"高频共现的模式"与"被验证为真的命题"。

这意味着：**流畅性与事实性在架构上没有被分离。** 这是当前架构的一个深层特征，也是 [#42 当前架构能否实现通用智能](42-architecture-limits.md) 讨论的一部分。

**（四）评测的不可复现性**

幻觉评测的分数极难在不同工作之间比较：提示词模板、解码参数、判分模型、去重规则任一变化都会显著改变结果。这使得"某方法把幻觉率降低了 X%"这类陈述往往无法被独立验证。这是 [#55 可复现性保证](55-reproducibility.md) 在本问题上的具体体现。

## 当前最好结果

| 方向 | 已知最好结果 | 出处 |
|---|---|---|
| 分类框架 | 三分法（input/context/fact-conflicting）+ 内在/外在幻觉二分 | Ji et al., 2023 |
| 检索增强 | RAG 显著降低事实性错误，但引入检索误差与"忽略上下文"两类新失败模式 | Lewis et al., 2020 |
| 不确定性估计 | 语义熵（在语义等价类上计算熵而非在 token 序列上）优于单次采样置信度 | Farquhar et al., *Nature*, 2024 |
| 校准 | 后处理校准（温度缩放等）在传统神经网络上有效；在 RLHF 模型上效果不稳定 | Guo et al., 2017 及后续工作 |
| 基准 | TruthfulQA 测"模仿人类谬误"倾向；FActScore 做原子事实精度评测 | Lin et al., 2022；Min et al., 2023 |
| 基准（短问答） | SimpleQA 采用"有确定答案 + 双人标注 + 对抗性采样"设计以降低污染风险 | OpenAI, 2024 |
| 自我认知 | 模型对自身正确性的预测优于随机，但可靠性不足以单独用于过滤 | Kadavath et al., 2022 |

**必须强调的限定**：上表中的"显著降低""优于"均指在**特定基准与设定**下的相对表现。目前**没有任何方法**在开放生成场景下把幻觉消除或降低到可忽略水平。任何声称"已解决幻觉"的说法都不成立。

## 解法现状与可行攻击路径

### 已解决的部分

存在若干**受限设定下**被实质解决的子情形：

- **受限设定下的幻觉检测可形式化并有可用方法**：多项选择、有明确答案的问答等受限设定下，检测问题本身是良定义的（见"为什么困难"第一节）。
- **短问答上的不确定性标注已被解决到可用程度**：语义熵（Farquhar et al., *Nature*, 2024）在短问答上效果明确——多次采样、语义等价类上计算熵，与错误率显著相关。
- **传统神经网络上的校准已被解决**：后处理校准（温度缩放等）在传统神经网络上有效（Guo et al., 2017）——尽管在 RLHF 模型上效果不稳定。
- **可形式化子问题有肯定答案**：给定 $N$ 次采样构造与事实错误高相关的统计量 $S$，这一子问题已被语义熵方向实质推进。

但**开放生成场景**下无任何被解决的真子情形——没有任何方法把幻觉消除或降到可忽略水平。

### 可行的攻击路径

| 路径 | 核心手段 | 当前状态 | 卡点 |
|---|---|---|---|
| 检索增强与工具调用 | 生成前检索证据、调用工具完成可验证子任务 | 工程上最成熟、收益最直接（RAG 已大规模部署） | 检索质量决定上限；模型可能忽略检索内容坚持参数记忆（context 冲突）；检索本身引入错误 |
| 不确定性量化 | 多次采样 + 语义等价类上计算熵（语义熵），标注不可信输出 | 短问答上效果明确，是最有希望的方向 | "语义等价"判定器本身可能出错；长文本生成的等价定义模糊 |
| 溯源与归因 | 要求给出支撑来源并验证一致性（FActScore 原子事实分解思路） | 可用于评测与过滤 | 归因验证器本身会出错；归因正确不代表事实正确（可正确引用有误文献） |
| 训练目标与解码策略 | 基于事实性的奖励模型、拒绝回答的训练、更保守的解码 | 方向存在但受激励机制制约 | 目标冲突：RLHF 奖励自信回答、诚实说"不知道"被扣分——是激励机制问题而非纯技术问题 |

### 已堵死的路径

**暂无已知的原理性排除结果。** 需要如实区分以下三类"看起来像排除"的障碍：

- 生成与验证的不对称性只是与 P vs NP 的**结构类比**，无归约关系，不构成对任何路线的排除；
- 流畅性与事实性在架构上未被分离，是当前架构的**特征**而非不可能性定理；
- 评测不可复现、基准污染是**方法论**层面的障碍，堵死的是"可信地测量进展"，不是任何解法路线本身。

### 裁决

**`已有部分解`**

| 裁决档 | 含义 |
|---|---|
| `已有部分解` | 有实质进展，可继续推进 |
| `条件可解` | 在某个未证假设下已有确定结论 |
| `路径已知，尚需突破` | 方向明确，但有硬卡点 |
| `原理上受限` | 已知障碍限制了主要证明技术 |
| `无已知路径` | 连攻击方向都不明确 |

受限设定下的检测与缓解（RAG、语义熵、校准）已有实质可用并在工程上大量部署的方法，属于"有实质进展，可继续推进"；但开放生成场景下没有任何方法消除幻觉，且缓解手段各自引入新失败模式，问题整体未被解决。

## 研究路线图

**路线一：检索增强（RAG）与工具调用**

让模型在生成前检索证据，或调用计算器/数据库等工具完成可验证的子任务。

现状：工程上最成熟、收益最直接。**卡点**：检索质量决定上限；模型可能忽略检索到的正确内容而坚持自身参数记忆（"context 冲突"）；检索本身可能引入错误内容。

**路线二：不确定性量化**

不试图消除幻觉，而是**标注出哪些输出不可信**。语义熵是目前最有希望的方向：对同一问题多次采样，把语义等价的答案聚成一类，在**类别分布**上计算熵。高熵意味着模型在多个不同答案之间摇摆，与错误率显著相关。

现状：在短问答上效果明确。**卡点**：聚类"语义等价"需要一个可靠的等价判定器，而它本身可能出错；对长文本生成，等价的定义变得模糊。

**路线三：溯源与归因**

要求模型给出答案的支撑来源，并验证来源与陈述的一致性（如 FActScore 的原子事实分解思路）。

现状：可用于评测与过滤。**卡点**：归因验证器本身会出错，且归因正确不代表事实正确——模型可以正确引用一篇本身有误的文献。

**路线四：训练目标与解码策略**

从训练层面减少幻觉倾向，如基于事实性的奖励模型、拒绝回答的训练、更保守的解码。

现状：**卡点**在于目标冲突。诚实地说"我不知道"在某些评测中会被扣分，而 RLHF 优化的是人类评分者的偏好。只要评分者奖励自信的回答，训练就会推向幻觉。这是**激励机制**问题，不只是技术问题。

## 常见误区

- **误区：幻觉就是模型在"编造"或"说谎"。**
  模型没有意图。幻觉是通过最大化下一个 token 概率的**自然产物**——当训练分布中某个错误关联出现频率足够高，或某个罕见事实缺乏足够训练信号时，流畅的错误输出就是在给定上下文下的**最优**解码结果。用"说谎"来描述会误导后续的所有技术判断。

- **误区：模型规模继续增大就会解决幻觉。**
  规模增大在**多数测量基准上**改善了事实准确性，但没有消除幻觉，且部分研究观察到某些类型的幻觉并不随规模单调下降。无论结论如何，**"架构不变 + 规模增大"本身不是一条原理性的解决路径**。

- **误区：RAG 能根治幻觉。**
  RAG 把问题从"参数记忆是否正确"转移为"检索与使用是否正确"，减少了部分错误但引入了新的失败模式。把 RAG 当作解决方案会在部署中产生新的、更隐蔽的错误。

- **误区：模型知道自己什么时候在胡说。**
  部分成立但不可依赖。模型的自我评估优于随机，但校准误差在分布外输入、需要多跳推理、或涉及罕见知识时急剧增大。把这种弱信号当作可靠过滤器，会带来虚假的安全感。

- **误区：某个基准上的高分证明幻觉已被解决。**
  基准分数受提示模板、解码参数、判分模型、数据污染的多重影响。跨工作比较分数通常无效。**看一个工作是否可信，看它是否报告了完整的评测配置与污染检查。**

- **误区：幻觉是模型"知识不够"导致的。**
  知识不足会引发错误，但幻觉的一个核心特征恰恰是**在缺乏知识时仍以高置信度输出**。核心问题是"不知道却不说不知道"，这是校准问题，不是知识容量问题。

## 可运行实验

**`experiments/hallucination_uncertainty.py`** — 语义熵与校准误差实测

这个脚本不需要 GPU、不需要模型权重，使用纯标准库实现两个核心概念的可运行演示：

**（一）期望校准误差（ECE）的构造与计算。** 脚本生成两组"模型置信度 — 实际正确率"配对数据：一组是良好校准的（置信度 0.8 时实际正确率约 0.8），一组是典型过自信的（置信度 0.95 时实际正确率约 0.6）。然后实现 ECE 的标准分箱计算，输出两个数值。

你会观察到：**过自信模型的平均置信度与实际准确率差距巨大，但它的"看起来对"的分数与良好校准模型相同。** 这个差距就是为什么"模型说自己很有把握"不能作为可信度依据。

**（二）语义熵 vs 单次采样置信度。** 脚本模拟 $N$ 次采样，每次是若干"答案字符串"。实现两种不确定性度量：
- 在**原始字符串**上计算熵（近似单次采样置信度）
- 先在**归一化后的语义表示**上聚类，再在类别上计算熵（语义熵思想）

构造的关键场景是：模型 8 次采样里给出了 5 种**措辞不同但语义相同**的表达（如"巴黎""法国首都""Paris"），和给出了 2 种**语义不同**的回答。前者字符串熵很高（看起来不确定），语义熵很低（实际很确定）。

**这个实验能说明什么**：语义等价类的粒度选择直接决定不确定性估计的质量，而"语义等价"的判定本身是需要独立解决的问题。

**这个实验不能说明什么**（重要）：它使用的是合成数据，**不构成对任何具体模型幻觉率的测量**。它演示的是度量方法的**构造逻辑与失效模式**。要得到真实结论，需要把 `--samples` 参数指向真实的模型采样输出（脚本支持从 JSON 文件读入）。

设计这个实验的目的，是让人在**不依赖任何 API 与算力**的前提下，亲手操作这两个核心概念，并看清它们各自会在哪里失效。
