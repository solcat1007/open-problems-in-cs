# #34 热带密码学中的离散对数问题

**状态**：`OPEN`
**领域**：密码学与信息安全
**首次提出**：热带密码学（tropical cryptography）作为具体提案，由 Grigoriev 与 Shpilrain 于 2014 年前后提出 `[待核实]`；其代数基础来自 1980–2000 年代热带代数与热带几何的发展。
**参与门槛**：可以立刻上手做实验

## 一句话概述

若把密码学建立在"热带半环"（tropical semiring）上的离散对数问题之上，这些体制是否安全？其中被用作陷门的困难问题，真的困难吗？

## 形式化陈述

**热带半环**：$(\mathbb{T}, \oplus, \otimes)$，其中 $\mathbb{T} = \mathbb{R} \cup \{+\infty\}$（或 $\mathbb{Z} \cup \{+\infty\}$），两个运算定义为

$$a \oplus b = \min(a, b), \qquad a \otimes b = a + b.$$

注意：$\oplus$（取最小）**不可逆**——没有加法逆元。因此这是一个**半环**，不是环，更不是域。

> **名词说明**："热带（tropical）"与气候无关，是数学界对巴西数学家群体的致敬式命名。

在该半环上取矩阵乘法 $\otimes$（与通常的矩阵乘法结构相同，只是乘法换成 $+$、求和换成 $\min$），定义矩阵幂
$$A^{\otimes k} = \underbrace{A \otimes A \otimes \cdots \otimes A}_{k \text{ 次}}.$$

**热带离散对数问题（tropical discrete logarithm problem, TDLP）**：给定矩阵 $A, B$，求整数 $k$ 使 $B = A^{\otimes k}$（在适当的良定义条件下）。

**开放问题**：TDLP（或热带密码学所用的其他陷门问题）是否存在**可证明的**困难性？据此构造的密钥交换与加密体制是否安全？

## 为什么困难

- **热带半环缺少群结构。** $\oplus$（取最小）不可逆，没有加法逆元。这既是"新颖困难问题"的来源，也意味着标准群论工具（指数映射、有限域上的离散对数理论、Diffie-Hellman 的群论分析）**完全不可用**。
- **困难性目前主要是经验性的。** 没有任何从已知困难问题（一般离散对数、格问题等）到 TDLP 的归约，也没有针对热带体制的公认复杂度下界。
- **热带线性代数可能反而"太容易"。** 热带线性方程组 $A \otimes x = b$ 的求解是热带线性代数中的经典问题，在小维度下存在多项式时间算法。若 TDLP 可归约为此类问题，则体制不安全 `[待核实]`。
- **已有若干攻击报告，但稳定性未经核对。** 有工作声称攻破了某些热带密码提案，但其适用条件、攻击复杂度与是否覆盖全部变体，需要核对原始文献 `[待核实]`。

## 解法现状与可行攻击路径

### 已解决的部分

- **结构层面的确定事实**：热带半环的 $\oplus$（取最小）不可逆、无加法逆元——因此标准群论工具（指数映射、有限域上的离散对数理论、Diffie–Hellman 的群论分析）在热带设定下**确定不可用**。这是已被确立的负面事实，不是猜想。
- **热带线性代数的基础已定**：小维度下热带线性方程组 $A \otimes x = b$ 存在多项式时间算法（经典结果）——若 TDLP 可归约到这类问题，则体制不安全 `[待核实]`。
- **可证明安全性层面无可罗列内容**：困难性无归约、无下界；已有若干针对具体提案的攻击报告，但其适用条件与覆盖面未经核对 `[待核实]`。该档案对"哪些提案已被攻破"的论述不足以支撑可靠罗列，建议后续核对原始文献补充。

### 可行的攻击路径

| 路径 | 核心手段 | 当前状态 | 卡点 |
|---|---|---|---|
| 归约到热带线性代数的攻击 | 把 TDLP 化为热带线性方程组等已知易解问题 | 被本档案判断为最有可能给出确定（负向）结论的路线 | 是否可归约 `[待核实]`；已有攻击报告的适用条件与覆盖面未经核对 |
| 建立困难性归约 | 把 TDLP 归约到已知困难问题，或直接证明 NP 难 | 尚无公认结果 `[待核实]` | 热带半环无群结构，缺少承载归约的代数接口 |
| 参数与密钥空间分析 | 分析密钥空间大小与已知攻击的复杂度 | 可立刻动手，产出经验数据 | 产出仅是经验数据，不构成安全性证据 |
| 转向更成熟的结构 | 改用格、椭圆曲线或编码 | 主流做法（"用脚投票"，引向 #35） | 属于放弃热带设定，非在本问题内推进 |

### 已堵死的路径

- **"结构新颖 ⇒ 自动困难"的设计路线**：困难性必须证明，不能从换一个新代数结构推出——这是热带密码学最根本的方法论堵死点。
- **标准离散对数工具的移植**：$\oplus$ 不可逆、无逆元，群论分析（离散对数理论、Diffie–Hellman 的群论论证）完全不可用——把经典 DLP 分析框架搬到热带设定的路线在根上不通。
- **"已被证明安全"与"已被彻底攻破"两个极端断言**：均缺乏经核对的公开结论——任何此类断言都要求提供可核查的归约或攻击。

### 裁决

**已有部分解**

实质进展集中在**负向**：攻击方向具体可行（归约到热带线性代数）、困难性缺失与多次质疑已被明确记录、主流已转向更成熟结构；正向（可证明困难性）则无任何结果。此处"部分解"指负向认知的推进，而非安全性的任何部分确立。

## 研究路线图

**路线一：寻找高效算法攻击。** 核心问题是热带矩阵方程 $A \otimes x = b$ 的可解性。若 TDLP 可归约为热带线性代数中的已知易解问题，则体制被攻破。此路线最有可能给出确定结论（负向）。

**路线二：建立困难性归约。** 把 TDLP 归约为某个已知困难问题，或直接证明其 $\mathrm{NP}$ 难。目前尚无公认结果 `[待核实]`。

**路线三：参数与密钥空间分析。** 即使在困难性未证明的前提下，也可以分析密钥空间大小与**已知**攻击的复杂度。此路线可以立刻动手，但产出的是经验数据。

**路线四：转向更成熟的结构。** 主流做法是放弃热带设定，改用格、椭圆曲线或编码——它们有更成熟的困难性归约（见 [#35](35-lattice-space-time.md)）。这本身是一种"用脚投票"。

## 常见误区

- **误区："热带"指气候或地理。** —— 它指 tropical semiring（min-plus 代数），名称来源于对巴西数学家群体的致敬式命名。
- **误区：热带半环是"群"，可以用标准离散对数理论分析。** —— 它是**半环**：$\oplus = \min$ 没有逆元。群论工具不可用。
- **误区：热带密码已被证明安全（或已被彻底攻破）。** —— 两个极端都缺乏经核对的公开结论。目前准确的描述是：**困难性未经证明，且存在质疑** `[待核实]`。
- **误区：换一个新代数结构代替有限域，就自动得到一个新的困难问题。** —— 困难性必须**证明**，不能从"结构新颖"推出。这是热带密码学最根本的问题。
- **误区：小规模实验显示暴力搜索很慢，所以体制安全。** —— 暴力搜索慢不能排除存在巧妙算法；见下面的实验节。

## 可运行实验

**`experiments/dlp_small_scale.py`** — 小规模离散对数暴力求解的复杂度实测（与 [#36](36-strongly-regular-graph-parameters.md) 共用脚本）

脚本对**小维度**热带矩阵幂做两件事：(1) 正向计算 $A^{\otimes k}$；(2) 用暴力搜索找出使 $B = A^{\otimes k}$ 的 $k$。作为对照，可对有限域上的经典离散对数做同样的实测。

**能观察到**：暴力搜索的代价随搜索空间呈线性 / 指数增长；对小维度热带实例，还可以观察是否存在**明显快于暴力**的结构化解法（例如借道热带线性代数）。

**绝不能说明**：

1. 小规模实测**不能**推出渐近结论——大维度的行为可能完全不同；
2. 它**不能**证明安全：暴力搜索很慢，也可能存在聪明算法；
3. 它**不能**证伪安全：搜索很快，也可能只是该小规模实例的偶然特殊性。

小规模数值实验在密码学中几乎从不构成安全性证据，**尤其在困难性未被证明时更如此**。这正是本档案要传达的核心警示。
