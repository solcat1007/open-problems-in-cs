# #20 Bodirsky–Pinsker 猜想

**状态**：`OPEN`
**领域**：计算复杂性理论 / 约束满足与模型论（constraint satisfaction）
**首次提出**：Manuel Bodirsky 与 Michael Pinsker，2011
**参与门槛**：需要新的数学工具

---

## 一句话概述

对于定义在**无限域**上、但具有良好对称性（齐次性、有限界性）的约束满足问题（constraint satisfaction problem，CSP），是否也存在"要么多项式时间可解、要么 NP 完全"的二分？有限域的版本已被证明，无限域是一块仍在开垦的疆土。

## 形式化陈述

设 $\mathfrak{B}$ 是一个**关系结构**：论域 $B$（可以是无限集，如 $\mathbb{Q}$）与一组有限元数的关系。

$$\mathrm{CSP}(\mathfrak{B}) = \{\,\text{有限约束集 } \Phi : \Phi \text{ 在 } \mathfrak{B} \text{ 中可满足}\,\}$$

**实例的表示**是必要的技术细节：约束集 $\Phi$ 是有限的，其元素是形如 "$(x_1, \dots, x_k) \in R$" 的约束，其中 $R$ 是 $\mathfrak{B}$ 的关系。因此即使论域无限，实例的输入长度仍然是有限的——这正是计算复杂性能被讨论的前提。

先看已知的图景：

- **有限论域的二分已解决。** Schaefer（1978）解决了布尔情形；Feder 与 Vardi（1998）提出了一般有限论域的二分猜想；Bulatov（2017）与 Zhuk（2017）独立证明了该猜想。这就是著名的 $\mathrm{CSP}$ 二分定理。
- **无限论域的一般二分**不成立。**若不对结构加以限制，可以构造出 CPS 复杂性任意（甚至严格介于 P 与 NP 完全之间）的结构。** 这一条极为关键：它说明"无限域"本身不是障碍，**缺少限制**才是。

**Bodirsky–Pinsker 猜想**（无限域 CSP 二分猜想）：对每个**有限签名下的有限界齐次（finitely bounded homogeneous）结构** $\mathfrak{B}$（一个与之密切相关的技术条件是 $\omega$-范畴性，$\omega$-categoricity），$\mathrm{CSP}(\mathfrak{B})$ 要么在 P 中，要么是 NP 完全的。

**猜想的两半，以及它的代数刻画形式**：

- **困难性一侧**：$\mathrm{CSP}(\mathfrak{B})$ 是 NP 完全的，当且仅当 $\mathfrak{B}$ 能够通过**原始正构造**（primitive positive construction，pp-construction）"模拟"出某个已知难的结构（例如 3-SAT 的模板，或更一般地，某个 CSP 为 NP 完全的**有限**结构）。
- **易解性一侧**：若 $\mathfrak{B}$ 不能 pp-构造出这类难结构，则 $\mathrm{CSP}(\mathfrak{B}) \in \mathrm{P}$。

pp-构造是有限域代数方法中的核心工具（通过 pp-公式从已知结构中"定义"出新结构）。猜想的内容可以概括为：**无限域 CSP 的复杂性完全由"它能 pp-构造出什么有限结构"决定**。

必须强调：**这是猜想，不是定理。** 本档案把它标为 `OPEN`。同时，本问题是本册中少数**没有已知原理性障碍**的问题——标为 `OPEN` 而非 `OPEN-BARRIER` 的原因正在于此。

## 为什么困难

**第一，有限域的证明工具在无限域上大面积失效。** Bulatov 与 Zhuk 的证明建立在对**有限代数**的深入运用之上——吸收性（absorbing）、Taylor 项、Tame Congruence Theory（相容性理论）、以及由有限性保证的"每个多项式闭包都有有限生成子代数"等结构性事实。当论域无限时：

- 有限代数的分类结果不再适用；
- 多项式闭包可以是无限代数，其上的相容性结构极其复杂；
- "有限生成"这一在有限世界自动成立的条件，在无限世界需要额外假设（这正是"有限界齐次"发挥作用的地方）。

**第二，PP-构造的判据需要把组合性质转成模型论/拓扑性质。** "$\mathfrak{B}$ 不能 pp-构造出难结构"这个条件很难直接验证——它需要对**所有**有限的 pp-构造作否定性断言。把这一条件等价为一个可操作的代数判据（例如"存在某个高阶对称性/同态"），是猜想证明的核心难点。

**第三，"有限界齐次"这个限制既是希望也是束缚。**

- 它是希望：正因为一般无限域的 CSP 可能有任意复杂性，没有它就没有二分可言。
- 它是束缚：有限界齐次性（等价于"可由一个有限结构的有限元数子结构上的同构类型刻画"）是一个**模型论意义上的强假设**，如何在证明中把它转化为算法上的可利用结构，至今没有统一手法。

**第四，缺少统一方法：目前是"逐族解决"。** 已知对大量具体的结构族证明了猜想（时间约束语言、空间、系统、系统发育相关的类，以及各种 Ramsey 结构的归约）[待核实：具体族清单与相应出处]。但这些证明各自依赖该族的特定表示与特定代数结构，**没有一条路线能覆盖所有族**。这与有限域情形形成了鲜明对照：有限域有一条统一的代数路线（吸收/Taylor/相容性），无限域目前没有。

**第五，"无限域的一般二分不成立"这一事实，使任何拟议的统一判据都必须能精确地把"良性"结构挑出来。** 如果判据过宽（例如只要求 $\omega$-范畴性），会被已知的反例击破；如果过窄，就无法覆盖已被证明的所有族。这个"恰好合适"的判据正是 pp-构造性猜想所主张的东西，而证明它需要双向工作：既要证明判据不足则多项式可解（算法方向），也要证明判据满足则 NP 完全（归约方向）。

**关于障碍的说明**：本问题**没有**已证明的原理性障碍（不涉及相对化 / 自然化 / 代数化三者的直接限制）。它的困难是**技术空白**型的：所需的模型论–代数–算法连接工具尚未建立。但它有一个**结构性约束**：一般无限域上二分不成立，因此"有限界齐次"这一限制不可省略。

## 当前最好结果

| 方向 | 已知最好结果 | 出处 |
|---|---|---|
| 有限域（锚点） | 布尔 CSP 二分 | Schaefer 1978 |
| 有限域（锚点） | 一般有限论域 CSP 二分定理（独立证明） | Bulatov 2017；Zhuk 2017 |
| 有限域（判据框架） | 代数方法：用多态（polymorphism）与吸收性刻画可解性 | Bulatov–Jeavons–Krokhin 2005；Feder–Vardi 1998 |
| 无限域（正向） | 对大量具体的有限界齐次结构族已证明二分 **[待核实：具体族清单与出处]** | Bodirsky–Pinsker 2011 及后续工作 |
| 无限域（负向） | 去掉"有限界齐次"限制后，二分不成立：存在复杂性介于 P 与 NP 完全之间的 CSP | 经典构造，见 Bodirsky 教材 |
| 判据（猜想的一部分） | pp-可构造性是"难"的候选判据（未证明其充分必要性） | Bodirsky–Pinsker 2011；Bodirsky 2021 教材 |
| 一般性 | **一般二分定理——未证明** | — |

严格区分：**上界**栏（"在 P 中"或"存在多项式算法"）与**下界**栏（"NP 完全"或"不在 P 中"）在本问题中构成猜想的两半；目前已证的结果是**逐个结构族**的两半，而不是统一定理。表中"无限域（负向）"一栏是**无条件**的结构性事实（存在反例），但它说的是"去掉限制后不成立"，而不是"猜想不成立"——这两者的区别务必分清。

## 解法现状与可行攻击路径

### 已解决的部分

- **有限论域这一受限制情形已被完全解决**：布尔 CSP 二分（Schaefer 1978）；一般有限论域二分定理由 Bulatov（2017）与 Zhuk（2017）独立证明——无限域猜想在有限域上的对应物已是定理。
- **大量具体的无限结构族已逐族解决**：时间约束语言、空间、系统发育相关的类，以及各种 Ramsey 结构的归约 [待核实：具体族清单与相应出处]。
- **无条件负向事实已确立**：去掉"有限界齐次"限制后二分不成立——存在复杂性任意（甚至严格介于 P 与 NP 完全之间）的无限域 CSP；这划定了猜想的适用边界。
- **判据的候选形式已提出**：pp-可构造性作为"难"的判据（尚未证明其充分必要性）。

### 可行的攻击路径

| 路径 | 核心手段 | 当前状态 | 卡点 |
|---|---|---|---|
| 逐族证明 | 对具体类（时间约束、空间、系统发育、Ramsey 结构归约）分别建立二分 | 已覆盖大量族 [待核实] | 每族需要专门方法，工作量难以收敛，无统一迁移机制 |
| 建立统一的代数/拓扑判据 | 证明"pp-构造性判据"的充分必要性 | 判据形式已被提出 | 无限域缺少有限代数中相容性理论的对应物 |
| 把模型论性质转成可计算结构 | 利用 $\omega$-范畴性、齐次性、Ramsey 性质、有限界性 | 有局部成果（如 Ramsey 结构在特定归约中的使用）[待核实] | 缺乏一般性定理 |
| 寻找反例 | 构造有限界齐次结构，其 CSP 严格介于 P 与 NP 完全之间（在 P ≠ NP 下） | 无此类反例 | 若成功即否证猜想；注意去掉限制后的反例存在，为猜想划定了不可跨越的边界 |

### 已堵死的路径

- **对全部无限结构统一论证**：已知存在复杂性任意的无限域 CSP，任何不带"有限界齐次"前提的统一二分路线被无条件反例排除——二分定理必须有前提。
- **有限代数工具的直接迁移**：Bulatov/Zhuk 的证明依赖吸收性、Taylor 项、Tame Congruence Theory 及"每个多项式闭包都有有限生成子代数"等由有限性保证的事实，这些在无限域大面积失效。注意：这是技术失效而非不可能性定理——本问题没有已证明的原理性障碍（相对化/自然化/代数化均不直接适用）。

### 裁决

**`路径已知，尚需突破`**

有限域版本的完整解决与大量无限族的成功给出清晰方向（统一判据 + 模型论到算法的转换），卡点是无限域缺少相容性理论的对应物、逐族方法无法收敛；猜想本身既未被证明也未被否证。

## 研究路线图

**路线一：逐族证明。** 对具体类（时间约束、空间、系统发育、以及各种 Ramsey 结构的归约）分别建立二分。现状：已覆盖大量族 [待核实]；**卡点**：每族需要专门方法，工作量难以收敛。

**路线二：建立统一的代数/拓扑判据。** 目标是证明"pp-构造性判据"的充分必要性。现状：判据形式已被提出，证明未完成。**卡点**：无限域缺少有限代数中的相容性理论对应物。

**路线三：把模型论性质（$\omega$-范畴性、齐次性、Ramsey 性质、有限界性）转成可计算结构。** 这是连接模型论与算法的最关键一环。现状：有局部成果（如 Ramsey 结构在特定归约中的使用）[待核实]；**卡点**：缺乏一般性定理。

**路线四：寻找反例。** 构造有限界齐次结构，其 CSP 严格介于 P 与 NP 完全之间（在 $\mathrm{P} \neq \mathrm{NP}$ 下）。若成功，猜想被否证。现状：无此类反例；但注意**去掉限制后**的反例是存在的，这为猜想划定了不可跨越的边界。

**哪条路被排除？** 任何试图对**全部**无限结构统一论证的路线——已知存在复杂性任意的无限域 CSP，因此二分定理必须有前提。

## 常见误区

- **误区：CSP 二分定理（Bulatov / Zhuk）已经解决了本问题。** —— **错**。他们的定理是**有限论域**的。本问题是无限论域，是完全不同的问题。
- **误区：无限域的 CSP 也有一般二分，只是尚未证明。** —— 需谨慎：**去掉限制后二分不成立**——存在复杂性介于 P 与 NP 完全之间的无限域 CSP。因此猜想的成立**依赖**"有限界齐次"这一限制。
- **误区：Bodirsky–Pinsker 猜想已被证明。** —— 它是猜想。已被证明的是**大量具体族**的二分。
- **误区：有限界齐次结构就是有限结构。** —— **不是**。典型例子如 $(\mathbb{Q}, <)$：论域无限，但结构具有有限界性与齐次性。混淆这两者会完全误解本问题。
- **误区：论域无限导致实例无法有限表示，所以问题没有意义。** —— 实例始终是**有限**的约束集，输入长度有限，计算复杂性完全有意义。
- **误区：pp-构造只是一个技术记号，无关紧要。** —— 它是猜想的核心内容：猜想的实质就是"复杂性由 pp-构造能力完全决定"。忽略它等于忽略猜想本身。
- **误区：本问题受自然化障碍限制。** —— 不受。它属于"技术空白"型困难，与 [#18](18-circuit-lower-bounds.md) 那类有明确障碍定理的问题不同。
- **误区：既然已对许多族证明，一般情形只是"工程问题"。** —— 各族证明依赖特有的代数结构，不存在统一的迁移机制，因此这不是工程量问题。

## 可运行实验

**`experiments/csp_temporal_toy.py`** — 验证已知正向结果的一个特例

实现一个**时间约束语言**（temporal constraint language）的小规模求解器：例如在稠密线性序 $(\mathbb{Q}, <)$ 上的约束满足，其可满足性可以归约为 2-SAT（或相应的多项式时间判定过程）。脚本生成随机小实例，同时用归约算法与暴力搜索求解，验证两者一致。

- **能说明什么**：对**这一类**结构，CSP 确实可以在多项式时间内求解——你会亲手看到归约如何把一个"无限域"问题化为有限的 2-SAT。
- **不能说明什么**：它验证的是已知正向结果在**一个族**上的特例，完全不能触及猜想本身；更不能提供任何下界（即它无法说明其他结构难）。

**`experiments/csp_dichotomy_exhaustive.py`** — 有限域二分的小规模穷举直觉

在布尔论域 $\{0,1\}$ 上穷举所有关系集合（对小的元数），对每个关系集合实现相应的 CSP 求解（暴力），并检查其可解性是否与 Schaefer 定理的六类易解情形吻合。

- **能说明什么**：Schaefer 二分定理在小规模上是**可逐项验证**的——你会发现易解与难的边界恰好落在定理预测的位置。
- **不能说明什么**：它只覆盖布尔、小元数的情形，与无限域猜想无关；把"有限域二分看起来成立"外推为"无限域也会有二分"正是被已知反例否定的推理。
