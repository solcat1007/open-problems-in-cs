Splay 树：自适应旋转与代价对比

本演示实现了标准 Splay 树（zig / zig-zig / zig-zag 三种旋转，实现与 Sleator–Tarjan 1985 原文一致），逐步动画展示访问后的伸展过程， 并把访问序列的总代价与静态最优 BST（动态规划精确计算）及静态树的信息论下界对比。 它对应仓库档案 ../volumes/02-algorithms-data-structures/problems/26-splay-dynamic-optimality.md（#26）。
它能说明什么：splay 的自适应行为——频繁访问的键会被转到浅处，重复访问变得越来越便宜（工作集性质）。
它不能说明什么：动态最优性猜想是"对任意访问序列，splay 的总代价与任何 BST 算法的最优代价差常数因子以内"。 本页只对比 splay 与静态最优树这两个具体算法、只展示有限条序列，既不能证明也不能否证猜想；侧栏的"下界"是静态树的信息论下界，不是动态 BST 的下界（后者需 Wilber 界，未在此计算）。

提示：输入"1 1 1 2 2 3 3 3 3 1 1"这类偏斜序列，观察 splay 的代价逼近甚至优于静态最优树（自适应性）； 输入随机均匀序列，两者接近。注意下界只约束静态树——动态 BST（包括 splay）可以低于它，这正是动态最优性研究的起点。
代价模型约定：为了可比性，三种度量统一为"搜索时走过的节点数"（= 被访问键在搜索开始时的深度 + 1）。 Splay 原文的标准代价模型（3×旋转数等）与伸展势能分析可由此乘常数得到；本页的对比在同一模型内进行，故公平。 静态最优树用访问频率（含首次插入）做经典 DP（Knuth 型），是"预先知道全部频率"情形下的最优静态树——splay 无需任何先验即可逼近它，这正是它的卖点。
本演示复现的是已知结果，不构成对开放问题的任何新贡献。
