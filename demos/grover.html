Grover 振幅放大：旋转、最优停止点与过冲

本演示把 N 维搜索空间中的 Grover 迭代投影到由「均匀叠加态 |s⟩」与「标记态 |w⟩」张成的二维平面上——这是教科书的标准画法： 每轮迭代让状态向量旋转 2θ（sin θ = 1/√N），成功概率 = sin²((2k+1)θ)。 它对应仓库档案 ../volumes/03-cryptography-security/problems/37-grover-exact-lower-bound.md（#37，其中"已解决的紧界 Θ(√N)"部分）。
它能说明什么：振幅放大的机制、"成功概率 vs 迭代次数"的正弦曲线、最优迭代次数 k* ≈ ⌊π√N/4⌋，以及过冲——迭代过多概率反而下降。过冲与峰的锐利性直观呈现了 √N 界的"紧"。
它不能说明什么：这是对 2 个振幅平面投影的可视化，不是对 N 维希尔伯特空间的完整模拟（每个基态的相位细节被略去）；它复现的是已知上界 Grover 算法的行为，不能证明 BBBV 的 Ω(√N) 下界——下界是关于所有量子算法的陈述。它也不涉及档案中真正开放的非关联 Oracle 模型。

怎么玩

  • 调 N：拖动 q = log₂N 滑块（3→8，即 N = 8→256）。观察：N 越大，初始角 θ 越小、每轮旋转 2θ 越小、k* 越大——这就是"√N 步"的直接来源。
  • 单步/自动播放：逐轮迭代，看向量扫向 |w⟩ 竖轴、绿色扇形（成功概率）变大。转过头（超过 k*）概率反而回落——注意右侧曲线上的红色过冲区。
  • 过冲实验：把 N 调小（如 8），连续点"迭代一步"穿过 k* 三四倍的距离，看正弦周期完整地走一遍。峰很窄——多转少转都显著变差。
  • 随机目标：换一个标记项。成功概率与 k* 只依赖 N，不依赖目标位置（这一对称性本身就值得注意）。
  • 精确模拟验证：页面底部可运行逐基态的完整模拟，与二维投影逐点对比——验证投影在单标记情形是精确的。

成功概率 vs 迭代次数

蓝点 = 当前迭代位置；绿线 = 最优停止点 k*；灰虚线 = 经典随机猜测对照（要走到同样概率需要 Ω(N) 次查询，Grover 只需 Θ(√N)）； 红区 = 过冲区（迭代超过 k* 后概率下降，直到下一个周期才回升——峰很尖，多转或少转都显著变差）。 这条正弦曲线正是 √N 界"紧"的原因：它由 2θ ≈ 2/√N 的微小步长累积而成，要走到接近竖轴必须 O(1/θ) = O(√N) 步，且没有"提前踩刹车"的自由度。
关于 k*：精确最优迭代次数由 BBHT（Boyer–Brassard–Høyer–Tapp 1998）刻画为 ⌊π/(4θ)⌋ ≈ π√N/4（当 θ = asin(1/√N)）。 本页曲线直接按解析式 P(k) = sin²((2k+1)θ) 绘制，与逐基态的完整模拟在 N ≤ 256 时数值一致（单标记情形下投影是精确的，略去的只是未标记态内部的相位结构）。

常见误区（取自档案 #37）

  • "Grover 的 Ω(√N) 下界尚未被证明"——恰恰相反：BBBV 1997 已给出与上界匹配的下界，标准无序搜索是已解决的紧界，不是开放问题。
  • "Grover 能破解所有对称密码"——它给的是平方根查询复杂度加速；实际攻击还受电路深度、量子内存、纠错等工程因素约束（档案 #59）。
  • "√N 是万能最优界"——只对无结构搜索成立；有结构的问题（如 Shor 的分解）可以多项式时间解决。
  • "精确成功也能 O(√N)"——精确搜索需要 Θ(N) 查询；√N 是有界错误情形的结论。
  • "本题未解决"——本题（#37）标为 PARTIAL 是因为非关联 Oracle 模型等削弱查询结构的变体仍开放；标准模型部分早已关闭。本演示模拟的正是标准模型。
密码学注脚：Grover 把对 2ⁿ 密钥空间的穷举从 2ⁿ 次查询降到约 2^(n/2) 次——这是对称密码安全参数减半的来源（AES-128 → 需按 2⁶⁴ 量子攻击评估）。但这只是查询复杂度；实际攻击还受电路深度、量子内存等工程因素约束（见档案 #59）。 精确成功（概率恰为 1）需要 Θ(N) 查询，√N 只对"高概率"成立——见档案"已堵死的路径"。
数学细节：2θ 旋转从何而来，k* 公式怎么推导

1. 状态空间压缩为二维。设 N = 2ⁿ，标记态 |w⟩，其余态的均匀叠加 |r⟩ = (1/√(N−1))·Σ_{x≠w}|x⟩。 初始态 |s⟩ = (1/√N)|w⟩ + √((N−1)/N)|r⟩ 落在 span{|w⟩, |r⟩} 平面内。 Grover 的两个算子都是反射：O 关于与 |w⟩ 正交的超平面反射（图中横轴方向不动、竖轴分量变号）， D 关于初始态 |s⟩ 反射。两次反射之积是一个旋转：D·O 恰好把这个平面里的状态向量朝 |w⟩ 方向旋转 2θ， 其中 sin θ = ⟨w|s⟩ = 1/√N。 所以 k 轮迭代后状态与横轴夹角为 (2k+1)θ，成功概率 = 该角正弦的平方：

P(k) = sin²((2k+1)θ)，θ = arcsin(1/√N)。

2. 最优迭代次数。要让 (2k+1)θ ≈ π/2（向量接近竖轴 |w⟩），需要 k ≈ π/(4θ) − 1/2。 由 sin θ ≈ θ ≈ 1/√N（N 大时），得 k* ≈ (π/4)·√N，精确公式为 k* = ⌊π/(4θ)⌋（BBHT 1998 的刻画）。 本页顶部显示的"理论最优 k*"用的正是精确式，右侧括注 ≈ ⌊π√N/4⌋ 是大 N 近似。

3. 过冲为何出现、下界为何因此是紧的。旋转步长固定为 2θ，没法"踩刹车"： 向量越过竖轴后 P(k) 开始下降，直到 (2k+1)θ = π − φ 后才回升——峰的宽度是 O(1) 而不是 O(√N)。 换句话说，不存在"运气好早点到"的迭代数：要把概率推到接近 1，任何逐轮使用同一个 2θ 步长的算法都必须走 Θ(1/θ) = Θ(√N) 步。 BBBV 的下界把这个直觉对所有量子算法（包括任意改变迭代策略的算法）严格化了，所以上下界匹配、界是紧的。

4. 本演示与完整模拟的关系。右侧"精确模拟"面板对全部 N 个复振幅执行 O（相位翻转）与 D（关于均匀叠加的反射）， 与投影公式逐点一致（偏差在 1e-15 浮点量级）。这说明单标记情形下二维投影不含任何近似； 真正被压缩掉的只是未标记态之间的内部相位结构——在"只问 P(测得 w)"这个意义上它们合并为一个方向是严格合法的。

5. 与经典对照。概率曲线图中的灰色虚线是经典随机猜测（每次查询独立猜一个项）的命中概率 1−(1−1/N)^k： 要达到 90% 需要约 2.3N 次查询，而 Grover 用约 (π/4)√N 次达到接近 1 的概率——两条曲线的横坐标之比正是平方根加速的直观形式。 注意比较的对象是"查询次数"而非"时间"；在标准的查询复杂度模型里这二者对 Grover 是一致的（每轮迭代一次预言机查询）。
